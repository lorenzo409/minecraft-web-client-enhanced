# Minecraft Web Client — custom improvements

This archive contains the original upstream project with a small, conservative gameplay default adjustment:

- **Render distance default: 4 chunks/units (instead of 3).** This provides a slightly wider view when a new profile is created, while remaining a modest setting for browser-based play.

## Notes

- Existing saved settings are retained and may override defaults.
- This is a source project, not a ready-to-launch packaged game. Dependencies must be installed and the project built/run according to the upstream README.
- The original upstream project and its license remain in place.
- I have not run a build in this environment, so the change is not build-verified.
